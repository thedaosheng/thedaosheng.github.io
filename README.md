# thedaosheng.github.io

Short bootstrap endpoints.

## Typeless Clipbridge

```bash
curl -fsSL https://thedaosheng.github.io/t | sh
```

With a peer:

```bash
curl -fsSL https://thedaosheng.github.io/t | sh -s -- --peer user@100.x.x.x
```

Readable alias:

```bash
curl -fsSL https://thedaosheng.github.io/tcb | sh
```
